## Ultra Downloader v1.0.0 (Multi-Audio Edition)

A high-speed Windows desktop utility to download 1080p video streams with all available multi-language audio tracks multiplexed into a single MKV container.

### Key Highlights
- **Multi-Audio Ripping**: Downloads all audio tracks available on the master playlist (English, Hindi, German, Spanish, Japanese, French, Korean, etc.) and packages them into an `.mkv` file with switchable tracks.
- **Auto-Bootstrapper**: Zero setup needed. The app automatically detects and configures `N_m3u8DL-RE` and `FFmpeg` on first run if missing.
- **Modern Dark UI**: Windows 11 style dark interface with live progress monitoring, speed indicators, and non-blocking terminal logs.
- **Developer Credit**: Developed with ❤️ by [XMON4U](https://github.com/Xmon4u).
- **Auto-Conflict Handling**: Automatic file deduplication to prevent overwrite prompts and crashes.
- **High Speed**: 16 concurrent threads for maximum throughput.

### Installation
Download `Ultra_Downloader_MultiAudio.exe` below and double-click to run. No installation or Python setup required.
