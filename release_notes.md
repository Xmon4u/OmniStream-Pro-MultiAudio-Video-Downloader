## NetMirror Multi-Audio Downloader v1.0.0

A portable Windows desktop utility to download 1080p video streams with all available audio languages multiplexed into an MKV container.

### Highlights
- **Multi-Audio Ripping**: Downloads all audio tracks available on the master playlist (English, Hindi, German, Spanish, Japanese, Russian, etc.) and packages them into a single `.mkv` with selectable audio tracks.
- **Auto-Bootstrapper**: Zero setup required. The executable automatically downloads and configures `N_m3u8DL-RE` and `FFmpeg` if not present on your system.
- **Modern Dark UI**: Windows 11 style dark interface with live progress monitoring and terminal logs.
- **cURL Parser**: Directly paste browser cURL commands copied from DevTools (F12) to bypass session and referer validation.
- **High-Speed**: 16 concurrent segment download threads for maximum throughput.

### Installation
Download `NetMirror_MultiAudio_Downloader.exe` below and double-click to launch. No Python or external dependencies required.
